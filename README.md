This code implements the population heuristic for the Vertex Coloring Problem described and used in:

E. Malaguti, M. Monaci, and P. Toth. A metaheuristic approach for the vertex coloring problem. INFORMS Journal on Computing, 20:302–316, 2008.
E. Malaguti, M. Monaci, and P. Toth. An exact approach for the vertex coloring problem. Discrete Optimization, 8:174–190, 2011.
